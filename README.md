# MMD Web Viewer

スマホのブラウザだけで動く MMD（MikuMikuDance）モデルビューアー。
PMX モデルと VMD モーションをその場で読み込んで再生し、スワイプで回転、
スマホの傾き（ジャイロ）でカメラが動くことで「フィギュアを手に持って眺める」体験を目指す。

GitHub Pages で配信される完全静的サイト（ビルドステップなし）。

## 使い方

1. スマホ（Android Chrome 推奨）で Pages の URL を開く
2. **モデル** — PMX ファイルとテクスチャ一式をまとめて複数選択する
   （対応環境なら **フォルダ** ボタンでモデルフォルダごと選択できる）
3. **モーション** — VMD ファイルを選択すると再生が始まる（ループ再生）
4. スワイプで回転、ピンチでズーム
5. **姿勢カメラ** を ON にして端末を傾けると視点が追従する
   （iOS Safari では初回にセンサー利用の許可を求められる）
6. **物理** トグルでスカート・髪の物理演算を ON/OFF できる（低スペック端末向け）

## 注意

- モデル・モーションのファイルは各モデルの利用規約に従うこと。
  このリポジトリにはモデルデータを一切含めない。
- 姿勢カメラは HTTPS でのみ動作する（GitHub Pages なら自動的に満たされる）。
